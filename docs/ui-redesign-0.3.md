# UI redesign 0.3 — sources & principles

## References (principles only; no brand cloning)
1. Things 3 calm hierarchy & whitespace — https://blakecrosley.com/guides/design/things · https://www.uiskillbook.com/design-md/things-3  
   → Today focus, quiet chrome, completed tasks recede, restrained accent.
2. Todoist Today view — https://www.todoist.com/help/todoist/get-started/plan-your-day-with-the-today-view-UVUXaiSs  
   → Landing on today, progress/completion affordance, bottom nav primary destinations.
3. Linear design refresh — https://linear.app/now/behind-the-latest-design-refresh  
   → Navigation recedes; content dominates; soft structure over loud borders; compact icons.
4. Mobile chat composer patterns — https://www.mobileappdesign.io/blog/chat-ui-design  
   → Large transcript, pinned bottom composer, single primary send, clear as secondary circular control.
